# LawLens 产品片 · 分镜 v4（以网站为主）

> v4 的改动：**全片以真实网站为主体**。9 章里 7 章是产品页面实拍（点击 / 滚动 / 推近），
> 图形动画只用于章节转场、数据看板与路线图。屏幕上「我们自己的界面」占比目标 ≥ 70%。
> 时长：8 分 00 秒 · 无旁白 · 中英双语字幕

---

## 一、为什么这么改

v3 的问题：31 个镜头里只有 1 个镜头（18 秒）是真实界面，其余是抽象卡片和流程图。
客户看完记住的是"排版好看"，不是"这个网站长什么样、点哪里、出什么"。

v4 的原则：

1. **每个能力都用页面证明**，不用文字描述代替
2. **动作必须真实**：光标点、页面跳、列表滚、区域推近——像有人在用给你看
3. **强调打在真实界面上**：压暗周围、放大焦点，而不是另做一张示意图
4. **图形只做三件事**：章节号、数据看板、路线图
