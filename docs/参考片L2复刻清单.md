## 五、我们不该抄的

1. **全片深色底**——我们用暖米色，抄颜色会割裂（已定）
2. **`LIVE · 真实操作录屏` 标注**——参考片用它区分"演示 vs 真实"，我们的整片都是真实界面，标了反而多余
3. **大量堆数字**——它的第三章靠数据密度打动人，我们的客户更在意"这条结论能不能用"，数字要少而准
4. **旁白**——参考片有旁白撑节奏，我们去掉后必须靠镜头运动补，不能照抄它的"静止 3 秒收尾"
