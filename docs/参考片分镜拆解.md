# 参考片分镜拆解（NodeCite · 8'14"）

> 之前做过不完整的分析：只抽了 28 帧、写了一段版式描述（见 `视频分镜台本.md` 第一节）。
> 这次是全片逐镜拆解：**2fps 抽帧 989 张 → 帧差检测切点 → 48 个镜头**，逐镜标注。

- 片源：`32601a6b…mp4`（960×544 / 22fps / 8'14" / 有旁白）
- 方法：每 0.5 秒抽一帧，灰度缩略图做帧差，阈值 7.2（高于 94 分位）判定为切点，短于 1 秒的抖动合并
- 结果：**48 个镜头**，平均 10.2 秒、中位 7.5 秒、最长 37.5 秒、最短 1.5 秒

---

## 一、时长分布

| 单镜时长 | 镜头数 |
|---|---|
| ≤ 2 秒 | 4 |
| 3–5 秒 | 16 |
| 6–10 秒 | 11 |
| > 10 秒 | 17 |

**关键发现**：它不是"快剪"片。近一半镜头超过 10 秒，最长一个 37.5 秒（产品录屏）。
节奏靠的不是切得碎，而是**每镜内部持续有动作**（打字、滚动、数字跳动、图谱生长）。

## 四、结构规律（比逐镜更重要）

**① 七章，每章三件套**

```
章节标题卡（4–8 秒，黑底大字）
  → 内容：信息板（8–16 秒）× 2–4 个
  → 内容：录屏（12–38 秒）× 1–2 个
```

**② 信息板与录屏交替，不连续堆同类**

同一章里，信息板讲完"为什么"，立刻切录屏"真的能"。第 03 章全是录屏（因为那章主题就是"能做到什么"），第 05 章全是信息板（主题是"解决了什么"，靠数据）。

**③ 每章最后落一句琥珀色结论**

`PAIN POINT · 痛点` 或大字断言，停 2–4 秒再切——这是全片唯一的"留白"。

**④ 数字必有对比**

不给孤立数字：`247 / 2,317`、`145 / 149`、`1.3% → 100%`、`41.8% / 45.9%`。对比才产生意义。

**⑤ 长镜头靠内部动作撑**

最长的 38 秒录屏里，界面一直在动：思考步骤逐条打勾、进度条推进、光标移动。没有一帧是静止的。

## 五、对我们的三条修正

1. **v5 定的"右栏 85% 都是网站"过头了。** 参考片只有 35% 录屏。建议改成
   **信息板 45% + 真实界面 45% + 标题卡/词卡 10%**——既露脸又讲得清。
2. **章节标题卡必须有。** 我们 v5 用词卡代替，但参考片是"章节卡（中文大标题）+ 词卡（英文金句）"两种，作用不同：章节卡负责分章，词卡负责喘气。
3. **数字要给对比。** 我们现在的"3,137 条""14 条结论"是孤立数字，应该配
   `3,137 条 / 全表 3,137 条，你这次只用到 11 条`、`14 条结论 / 人工抽样通常 5–6 条`（后者需有依据，否则不放）。
