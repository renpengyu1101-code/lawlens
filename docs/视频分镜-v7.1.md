# LawLens 视频分镜 v7.1（快节奏 · 依据产品说明 v2）

> v7.1 修正两处硬伤：**① 章节卡标题「这是一台什么机器？」不成立**（产品不是机器，这句话没有信息量）；
> **② 章节卡的时间位置与章号对不上**（卡在上一章结尾，编号却是下一章）。
> 本版重排：每章 = **2 秒章卡 + 内容**，卡号与章号一一对应。

- 目标：**6 分 00 秒** · 84 镜 · 平均单镜 3.6 秒
- 无旁白，中英双语字幕；暖米色主色，墨黑只用于章节卡与词卡
