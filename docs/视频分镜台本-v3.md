## 一、没有旁白，节奏靠什么撑

取消配音后，观众的注意力全部落在**画面变化**和**字幕**上。三条规则：

**① 字幕可读性**
- 中文单屏 ≤ 18 字，英文单屏 ≤ 12 词
- 停留时长 = 字数 ÷ 5 秒（即每秒读 5 个汉字），最短 2.4 秒，最长 4.0 秒
- 中英同屏，中文在上（28px），英文在下（18px，0.64 倍）

**② 每镜必须有一次"视觉事件"**
不允许"画面不动、字幕换行"。每个镜头至少包含一次：推近 / 压暗 / 描边 / 跳色 / 数字滚动 / 图层位移。

**③ 重点必须被"打光"**
全片设 12 个重点时刻（下表标 ★），处理方式二选一：
- **单点放大**：焦点区域 scale 1.0 → 1.12，其余压暗到 28%、加 2px 高斯模糊
- **聚光压暗**：非焦点区域叠一层 `rgba(20,18,16,0.62)`，焦点保持原亮度，边缘 120px 羽化

实测经验：一次强调 0.6–1.2 秒最舒服；超过 2 秒观众会以为卡住了。

## 五、强调手法的技术规范

| 手法 | 实现 | 参数 | 用在哪 |
|---|---|---|---|
| 单点放大 | 焦点元素 `scale` + 容器 `overflow: hidden` | 1.0→1.12（页面元素）/ 1.0→1.35（数字），0.45s `cubic-bezier(.2,.8,.2,1)` | 3-4 / 3-5 / 4-4 / 5-2 |
| 聚光压暗 | 非焦点区域叠 `rgba(20,18,16,0.62)`，`mask-image` 径向羽化 120px | 0.5s 淡入 | 1-3 / 3-2 / 4-2 / 6-2 / 7-2 |
| 描边高亮 | `outline: 2px solid #9a6425` + `outline-offset: 6px` | 0.3s 出现，停留 1s 后淡化 | 2-2 / 4-1 / 7-4 |
| 跳色 | 关键字 `color` 过渡到 `#9a6425` + 下划线 `scaleX 0→1` | 0.35s | 3-6 / 5-3 / 6-1 / 7-3 |
| 静帧 | 一切动效停止，只留光晕呼吸 | 0.8–1.2s | 1-4 / 8-2 |

**禁忌**：同一镜头不要叠加三种以上手法；不要用抖动、闪烁超过 2 次；不要在字幕换行时同时做放大（观众会读不完）。

## 六、红线（与前版一致）

1. **路线图章节标「ROADMAP · 规划中」**，不得用真实界面截图冒充。
2. **案例为虚构脱敏材料**，3-1 字幕已注明「脱敏虚构」。
3. **数字只用一套口径**：页面显示「折合 18.5 / 95 · 覆盖度 75% · 暂不定级」。
4. **免责出现两次**（5-4 与 8-2）。

## 七、制作顺序建议

1. 先做 **01 + 03**（痛点 + 案例），这两章含 6 个强调点，最能体现"打光"效果
2. 再做 02 / 04（流程 + 可信机制）
3. 最后 05–08（评分、数据、路线图、片尾）
