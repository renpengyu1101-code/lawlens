# 四个 Agent 的视觉表达方案

> 问题：视频里用什么代表四个 Agent，才能让观众一眼分清"谁在干活"，同时不显得幼稚、不和法律产品打架。

---

## 一、先排除三种做法

| 做法 | 为什么不用 |
|---|---|
| **拟人化角色**（小人、机器人、吉祥物） | 法律产品用吉祥物会削弱专业感；客户是律师，看到卡通形象会出戏 |
| **纯光点 / 粒子** | 抽象到没有身份，"哪个是质检"根本分不清 |
| **纯文字标签** | 能分清但没有"在运行"的感觉，动态段落会变成幻灯片 |

---

## 二、采用：**工作徽标（Worklet）**

一个 56 像素的圆形徽标，由三部分构成：

```
   ╭─────────╮
   │    ◠    │   内层：几何符号（四个 Agent 各一个）
   │         │   外环：状态环（转 = 工作中，不动 = 待命）
   ╰─────────╯
   ● 质检 Agent    下方：名字（20px，灰色）
```

**为什么是圆形徽标**：圆形没有方向感，可以出现在画面任何角落（右上角、材料旁边、输入框旁）而不打断构图；方形卡片只能排在版面上。

---

## 三、四个符号（靠形状区分，不靠颜色）

符号要满足两个条件：**小尺寸（56px）能认出来**、**和它的职能有语义关联**。

| Agent | 符号 | 形状 | 语义 |
|---|---|---|---|
| ① 语言识别 | **双引号 + 弧线** | `"` 加两道同心弧 | 从人话里提取信息 |
| ② 资料 | **扫描框** | 方框 + 一条斜线穿过 | 逐份扫、逐页提 |
| ③ 分析 | **交错双环** | 两个 30° 相交的圆环 | 两条数据流交汇计算 |
| ④ 质检 | **盾 + 勾** | 盾形轮廓内一个 √ | 核验、拦截 |

四者在 56px 下的辨识度：引号（左上缺口）／方框（直角）／双环（曲线交叉）／盾（下尖）——形状差异足够大，不会混。

---

## 四、颜色规则（只有一套）

不给每个 Agent 单独配色——四个颜色在暖米底上会变成"调色盘"，也会和产品界面的金/墨体系打架。

| 状态 | 内圈符号 | 外环 | 名字 |
|---|---|---|---|
| 待命 | 灰 `#928f86` | 灰，静止 | 灰 |
| 工作中 | 金 `#9a6425` | 金，顺时针转（2 圈/秒），环上有 3 个亮点跟随 | 墨 `#17181a`，加粗 |
| 完成 | 墨 `#17181a` | 墨，静止，缺口闭合 | 灰 |
| 异常 | 红 `#a8402f` | 红，静止 | 红，附「退回」小标 |

**一句话**：颜色只表达状态，不表达身份；身份靠符号形状。

---

## 五、四种状态 + 动效参数

| 状态 | 动效 | 时长 |
|---|---|---|
| 出现 | 从 0.7 缩放 + 淡入 | 0.35s |
| 转入工作 | 外环从灰转金，转速 0 → 2 圈/秒 | 0.4s |
| 工作中（持续） | 3 个亮点沿环运动，每 0.9s 一圈 | 循环 |
| 完成 | 转速归零，环缺口闭合成实心环，内圈打勾闪一次 | 0.5s |
| 异常 | 环变红 + 徽标抖动 2px + 弹出「✕」 | 0.4s |
| 退回 | 徽标沿红色虚线飞向目标（仅质检用一次） | 1.2s，0.5 倍速 |

---

## 六、驻场位置（案例章版面）

四个徽标**不堆在角落**，各自驻在自己的工作区旁边——观众看哪块画面，哪个 Agent 就在附近。

```
┌──────────────────────────────────────────────────────────┐
│                                              ● 质检 Agent │  ← 右上角，全程常驻
│   ┌─ 输入区 ─┐                                            │
│   │ 评估我们… │  ◉ 语言识别 Agent                          │
│   └──────────┘                                            │
│                                                           │
│   ┌ 材料网格 ─┐        ┌── 计算核 ──┐                     │
│   │ ▣ ▣ ▣ ▣  │        │    ◎      │  ◉ 分析 Agent        │
│   │ ▣ ▣ ▣ ▣  │  ◉ 资料 │  ~~~~~~~   │                     │
│   └──────────┘     Agent└───────────┘                     │
└──────────────────────────────────────────────────────────┘
```

| Agent | 位置 | 何时出现 |
|---|---|---|
| 语言识别 | 输入框右上方（x≈820, y≈300） | D1 开始 |
| 资料 | 材料网格右侧（x≈780, y≈700） | D2 开始 |
| 分析 | 计算核右侧（x≈1300, y≈560） | D3 开始 |
| 质检 | 画面右上角（x≈1760, y≈120） | **D1 一开始就出现，全程不退场** |

**质检为什么常驻**：它是"全程监督者"的角色，中途消失会削弱"贯穿全程"的表达。

---

## 七、什么时候徽标变卡片

徽标只负责"在场感"，讲职责时还是要卡片：

| 场景 | 形态 |
|---|---|
| D1–D4 跑流程 | **徽标**（56px）+ 名字 |
| 需要讲某个 Agent 的职责（约 4 秒） | 徽标**放大到 1.35 倍**，旁边浮出 2 行说明（职责 / 输入输出） |
| 章节总览（四 Agent 齐活） | 四个**卡片**（320×120）横排，徽标在卡片左上角 |

过渡规则：徽标放大 → 卡片从徽标位置展开（不是另起一个位置），观众视线不跳。

---

## 八、和"库"的视觉区分

库是**方形卡片**（420×150，米白底），Agent 是**圆形徽标**（56px，线条）。方与圆、面与线——两类元素一眼可分，不会混淆。

连线方向也用形状区分：
- **库 → Agent**（取数）：金色细线 + 流动粒子
- **Agent → 库**（写回）：墨色虚线 + 反向粒子

---

## 九、落地成本

| 项 | 工作量 |
|---|---|
| 四个符号（SVG 手绘） | 0.5 天 |
| 徽标组件（四状态 + 动效） | 0.5 天 |
| 放大成卡片的过渡 | 0.5 天 |
| 在 D1–D4 里布点 | 0.5 天 |
| **合计** | **约 2 天** |

---

## 十、需要你确认的三件事

1. **符号方案**：引号 / 扫描框 / 双环 / 盾勾——这四个形状你是否认可？如果有更贴切的（比如"资料"用文件夹、"质检"用放大镜），我改。
2. **徽标 vs 拟人**：确认不走拟人路线（我建议不走）。
3. **质检常驻**：是否同意它从 D1 就出现在右上角、全程不退场？这是"贯穿全程"最直接的表达，但也意味着画面右上角长期占一块。
