## 怎么试

1. 登录后在工作台对话框里写一句，例如：
   「核查核心资产权属、租赁、资质与知识产权」
2. 知识库选「资产权属要点库」，主体填「澜川精密制造有限公司」。
3. 附件一次选中 **除 V2 之外** 的所有 docx（V2 是给版本测试用的），点「开始核查」。
4. 进入项目页后，在「材料与版本」里找到「资产-01-不动产权证摘录」这一组，点「上传新版本」，选 `资产-01-不动产权证摘录-V2.docx`，再点「对比最近两版」。
