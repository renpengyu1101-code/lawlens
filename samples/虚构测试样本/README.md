# 虚构测试样本（演示专用）

本目录全部文件由脚本 `scripts/make_samples.py` 生成，**公司名、证号、金额、日期均为虚构**，
与任何真实企业、不动产、权利证书无关，仅用于演示系统能否发现问题。

刻意设置的瑕疵（用于验证四个 agent）：

| 文件 | 瑕疵 | 预期识别 |
|---|---|---|
| 01-不动产权证摘录 | 已办理抵押登记 | AST-03 权利负担 |
| 03-房屋租赁合同 | 出租方为物业公司，非产权人 | AST-04 租赁合法性 |
| 04-商标注册证摘录 | 已办理质押登记 | AST-03 权利负担 |
| 05-增值电信业务经营许可证 | 有效期至 2025-12-31，已过期 | AST-05 资质有效性 |
| 06-专利证书摘录 | 专利权人为自然人李某某，非拟上市主体 | AST-01 权属主体一致性 |
| 06 与 01/04 | 权利人记载不一致 | AST-06 材料冲突 |

> 使用限制：不得将本目录材料或据其生成的报告用于任何真实交易、尽调或法律结论。
