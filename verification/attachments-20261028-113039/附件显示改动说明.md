# 附件名称与上传进度：改动及验证记录

状态：功能修改、制作人自测和独立复校完成；独立复校结论通过，详见[复校清单](复校清单-附件显示.md)。

## 改动与来源

- [S1]【有来源】工作台先保存所选 File 列表，再清空文件输入框，避免延迟执行的状态更新读到空列表。附件区显示完整文件名、字节数、待上传提示，提交前可移除文件。来源：[Dashboard.jsx](../../frontend/src/pages/Dashboard.jsx)、[AttachmentList.jsx](../../frontend/src/components/AttachmentList.jsx)。
- [S2]【有来源】上传百分比来自 XMLHttpRequest 的实际请求体传输事件，代表本批附件总进度（包含表单封装），不是每份文件的处理进度。发送完毕显示“正在处理文件”，收到成功响应才显示“上传完成”；失败保留文件名并显示错误。工作台、项目页追加材料、新版本上传共用该机制。来源：[api.js](../../frontend/src/api.js)、[ProjectDetail.jsx](../../frontend/src/pages/ProjectDetail.jsx)。
- [S3]【有来源】项目页追加材料成功后刷新材料与版本列表；上传期间禁用会冲突的上传和核查操作。来源：[ProjectDetail.jsx](../../frontend/src/pages/ProjectDetail.jsx)、[ui.log](ui.log)。
- [S4]【有来源】前端构建成功，8000 服务首页引用本次构建的脚本。构建前的依赖检查有 esbuild 构建脚本未获准执行的提示，随后 Vite 使用现有依赖完成构建；未更改该依赖策略。来源：[build.log](build.log)、[served-build.json](served-build.json)。
- [S5]【有来源】后端自测 47 项通过，界面自测 45 项通过。界面检查包含附件选择、移除、实际限速上传、断网失败、恢复网络重传、材料与版本刷新。后端使用本目录 smoke-data，界面测试服务使用本目录 ui-data 和 8011 端口。本次修改范围为前端及UI测试脚本，未编辑后端（据主代理执行记录说明）。冒烟脚本按原有行为重新生成了 samples/示例报告（虚构样本）.docx。来源：[smoke.log](smoke.log)、[ui.log](ui.log)、[server-error.log](server-error.log)、[smoke_test.py](../../scripts/smoke_test.py)、[ui_check.mjs](../../scripts/ui_check.mjs)。
- [S6]【有来源】Codex 子代理 attachment_review 已独立核对源码、构建及测试日志、四张附件截图和来源登记项，并签署[复校清单](复校清单-附件显示.md)。核对登记项 6 条，实质不一致 0 条；S6 的旧待补状态已随复校完成更新。本次为日志独立复核，复校人未重新执行测试。

## 验证限制及复校修订

- 第一次界面测试在选择附件后超时，记录保存在 [ui-initial-failure.log](ui-initial-failure.log)。检查发现文件列表读取发生在 React 更新回调内，而输入框已经清空。改为同步保存 File 列表后重新构建，最终检查通过。
- 完成状态截图初次拍摄早于材料列表刷新结束。随后收紧测试等待条件，要求材料列表、版本列表、按钮状态均已更新，再重新执行界面测试。
- 文件较小时传输阶段可能很短，无法保证肉眼能看到每一个百分比；不使用模拟延时伪造进度。
- 本次未验证模型调用、法律依据及其他业务结论的正确性。
